# TheNewSuzerain

TNO + Suzerain.

The game is being built in Godot 4.7 (.NET). What's here:

| Folder | What it is |
| --- | --- |
| `tns-godot/` | The Godot project: the folding world map, its terrain and the tools that make the terrain. Start with `tns-godot/README.md`. |
| `thenewsuzerain_notes/` | Design notes on the game's countries, regions and UI (an Obsidian vault). |

The baked terrain the map is drawn from (2.7 GB) isn't in git; it's attached to a GitHub release.
`tns-godot/README.md`, under "Running", explains how to get it.

The earlier Unity version of the project is kept on the `unity` branch.
